⚙ Persiapan Items Rename

Agar tampilan item rename Annum muncul dengan benar, pasang mod CIT Resewn dan gunakan texture pack Annum.

  1. Pastikan Minecraft Java kamu menggunakan Fabric.
  2. Unduh CIT Resewn yang sesuai dengan versi Minecraft kamu, lalu pasang file mod-nya ke folder mods.
  3. Unduh texture pack Annum dan aktifkan melalui menu Resource Packs di Minecraft.
  4. mod wajib ini khusus untuk versi 1.21.4 kebawah, jika versi Minecraft mu 1.21.4 keatas maka kamu tidak perlu menggunakan mod ini

ANNUM HARDCORE

Peraturan & Informasi

Ketentuan selama bermain di Annum Hardcore.

01

Random Spawn

Saat pertama kali memasuki server, lokasi spawn kamu akan ditentukan secara acak.

02

Starter Kit

Setiap pemain dapat mengklaim kit awal menggunakan perintah /kit melalui chat.

03

Sistem Limbo

Jangan sampai mati! Setiap pemain yang mati akan dipindahkan ke dunia Limbo.

04

Death Penalty

Setiap kematian akan menggandakan waktu hukuman (x2), sesuai jumlah kematian yang dialami.

05

Netherite Disabled

Ancient Debris dan Netherite dinonaktifkan selama 5 hari, terhitung sejak server resmi dibuka.

06

World Border

Overworld: 7000 × 7000 blok

Nether: 3500 × 3500 blok

07

Mace Event

Hanya terdapat 1 Mace di seluruh server. Mace tersebut akan menjadi hadiah dalam event khusus.

08

Nether Lock

Dimensi Nether akan ditutup selama 3 hari sejak server dibuka.

09

The End Disabled

Dimensi The End tidak akan dibuka selama server berlangsung.

10

Roleplay System

Sistem Roleplay akan tetap berjalan selama terdapat pemain yang online, kecuali ketika pemain sedang AFK.

11

Mending Event

Mending tidak dapat diperoleh melalui cara biasa. Event Mending akan diadakan 1 kali setiap minggu dengan durasi 1 jam.

12

Mending melalui Saweria

Pemain juga dapat memperoleh Mending melalui Saweria Admin dengan harga Rp10.000 untuk 1 Mending.

ANNUM HARDCORE

Harap pahami seluruh aturan sebelum bermain. Setiap pemain wajib mengikuti ketentuan yang telah ditetapkan.
